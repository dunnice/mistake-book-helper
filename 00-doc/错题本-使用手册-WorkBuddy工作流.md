> **出品人**：ice7  
> **用途说明**: AI Agent 智能错题本日常使用指南。  
> **核心机制**: **错题本的输入依托 AI Agent（智能助手）进行批改与结构化写入**，用户日常无需手动繁琐打字，只需拍照批改，即可完成高质量错题建档。

## 一、用户极简操作三步法

### 第一步：手机拍照或扫描卷子
- 把做完的作业、练习卷或考试卷子，通过手机直接拍照发送给 AI 智能助手。
- 可附带简短语音或文字说明，例如：“批改一下这张英语月考卷”、“ice7 数学 八上 期中模拟卷”。

### 第二步：AI 自动批改与错题提取
- AI 智能助手启动学科视觉大模型识别，逐题判定对错；
- 对做错的题目，AI 自动完成：
  1. **提取完整题干与选项**；
  2. **提炼学生的错误答案与标准正确答案**；
  3. **定位初中课标标准知识点标签**（如“一元二次方程根的判别式”、“定语从句”）；
  4. **生成深度考点精析、解题关键思路与避坑指南**；
  5. **智能归类错因**（概念不清 / 计算失误 / 审题错误 / 方法不会 / 粗心马虎）。

### 第三步：下达指令，一键入库
- AI 诊断完成后，在对话框列出待入库错题清单；
- 用户回复指令：“**收集到错题本**” 或 “**上传错题**”；
- AI 智能助手自动调用云端 API，将清洗好的结构化数据批量写入错题本服务。

## 二、日常常用 AI 语音/文字指令

| 用户日常指令 | AI Agent 执行动作 |
|---|---|
| 「**收集到错题本**」 / 「**上传错题**」 | 将刚才批改出的所有错题打包通过 API 写入系统，返回各题编号 |
| 「**我这周数学有哪些错题还没掌握？**」 | 查询 `/api/v1/questions`，筛选出状态为“待重做”的错题并汇总输出 |
| 「**我哪个板块最薄弱？**」 | 调用 `/api/v1/stats` 统计看板，诊断未掌握错题最多且通过率低的知识点 |
| 「**帮我出一份 10 题的错题重做卷**」 | 给出打印建议，并推荐进入打印组卷页一键生成 A4 纸质复习练习卷 |

## 三、系统完整闭环流程图

```
┌─────────────┐       ┌────────────────────────┐       ┌────────────────────────┐
│  手机拍卷子   │ ────> │   AI Agent 智能批改    │ ────> │ 结构化清洗与规范化打标  │
└─────────────┘       └────────────────────────┘       └───────────┬────────────┘
                                                                   │ (X-API-Key POST)
                                                                   ▼
┌─────────────┐       ┌────────────────────────┐       ┌────────────────────────┐
│ 统计与周复盘 │ <──── │ 手机扫码对答案/判对错  │ <──── │ 打印组卷(A4纸质,带独立码)│
└─────────────┘       └────────────────────────┘       └────────────────────────┘
```

1. **输入端（智能层）**：AI Agent 作为智能输入源，杜绝人工手动抄题的痛苦；
2. **存储端（数据层）**：阿里云 Go 后端 + 数据库，永久保存，自动执行“连续 2 次做对 = 已掌握”的判定规则；
3. **输出端（纸质层）**：打印组卷页直接 A4 纸张排版打印，题目带独立扫码二维码，**卷面上不印答案**，防止抄答案；
4. **反馈端（练习层）**：做完后手机微信或相机扫码，查看 AI 详尽解析，点击“我做对了”或“还是做错了”，系统自动更新掌握状态。
