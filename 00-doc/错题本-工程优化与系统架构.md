## 1. 工程优化概览

为提升系统的可维护性、开发体验与工程规范，本项目进行了系统化的工程化重组：

1. **前端工程独立化 (`mistake-book-view`)**：
   - 采用 **Vue 3 + TypeScript + Vite** 现代技术栈；
   - 视觉体系参考并复用 `teamwork-front-view` 的设计语言（macOS 悬浮胶囊 Dock 导航、毛玻璃质感、细腻阴影与卡片体系）；
   - 集成 `lucide-vue-next` 现代矢量图标库与 `echarts` 统计图表看板；
   - 模块涵盖错题工作台、多维筛选、AI 详解抽屉、重做历史打卡、A4 纸质打印组卷排版、移动端免密答题、系统配置等。
2. **后端工程模块化 (`mistake-book-go-api`)**：
   - 将散落在根目录的 Go 代码收拢至 `mistake-book-go-api/`；
   - 增加开箱即用的跨域（CORS）支持，支持前后端分离热更新开发；
   - 增强静态资源目录自适应探测与 SPA 路由托管能力，支持单容器全栈打包。
3. **技术文档集中管理 (`00-doc`)**：
   - 将工作流手册、实施方案、设计文档、运维手册集中收纳至 `00-doc/` 统一维护。
4. **统一脚本规范 (`script`)**：
   - 编译、构建与启动脚本全部归拢至 `script/`，支持本地构建与 Linux 跨平台交叉编译；
   - 根目录提供友好简洁的 `Makefile` 指令驱动。

## 3. 开发与构建指令

### 3.1 本地全栈开发

```bash
# 方式一：通过 Makefile（推荐）
make dev

# 方式二：直接执行脚本
./script/dev.sh
```
- 后端服务：`http://127.0.0.1:8080`
- 前端页面：`http://127.0.0.1:5173`（带热重载与反向代理）

### 3.2 编译与产物构建

```bash
# 一键编译全栈（前端 + 本地 Go 二进制）
make build

# 仅编译前端 Vue 项目
make build-web

# 仅编译后端 Go 项目
make build-api

# 交叉编译 Linux (amd64) 部署二进制
make build-linux
```

## 4. 关键功能亮点

| 模块 | 功能说明 | 核心交互与特点 |
| :--- | :--- | :--- |
| **错题库工作台** | 错题集中管理与检索 | 顶部指标卡片、科目/状态胶囊筛选、关键字全文检索、卡片瀑布流 |
| **错题详情与重做** | 题目精析与打卡 | 题干与选项展示、错误答案 vs 正确答案对比、AI 深度解析、一键记录做对/做错 |
| **统计分析看板** | 错题多维归因剖析 | 易错知识点排行榜（柱状图）、学科错题占比（环形图）、错因根因分析 |
| **A4 纸质打印组卷** | 线下针对性强化 | 仿真 A4 纸张排版、按科目/数量抽取题目、自动在右上角附加免密答题二维码 |
| **移动端免密答题** | 手机端沉浸练习 | 手机扫码直达 `/m/:id`，先隐去答案自主练习，做完后展开核对并一键打卡 |
| **系统配置与凭证** | 鉴权与服务端对接 | API Key 安全存储管理、连通性实时检测、Base URL 自由切换 |
