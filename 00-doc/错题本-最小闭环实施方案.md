## 一、总体架构（最小闭环版）

```
手机 AI Agent ──拍照──▶ AI Agent 批改/提取/打标（智能层）
                             │ 说"上传错题" → 调用错题本 skill
                             ▼
        POST /cuoti/api/v1/questions  (X-API-Key 鉴权)
                             ▼
nginx(5173) /cuoti/* ──▶ Go 服务(127.0.0.1:8090, systemd) ──▶ MySQL(本机3306)
                             │
        ├─ /cuoti/           错题管理页（列表/详情/统计）
        ├─ /cuoti/print      打印组卷页（每题带二维码）
        └─ /cuoti/m/:id      手机扫码页（隐藏我的答案 + 提交对错）
                             ▲
对话内查询 ◀── GET /api/v1/stats、/questions ── AI Agent 分析薄弱板块 / 生成快照网页
```

## 二、五项需求的实现方案

### 1. 手机拍照 → AI 批改、识别错误、分析知识点
**原生支持，零开发**。你在手机端向 AI 智能体发送卷子照片，AI 逐题批改、提取错题、按初中知识体系打知识点标签、生成详解。批改完展示"待入库清单"等确认。

### 2. 上传题库 skill（含基础 token 鉴权）
新建用户级 skill `~/.workbuddy/skills/mistakebook/SKILL.md`，内容：
- 服务地址 `http://${SERVER_IP}:5173/cuoti` + API Key（存 skill 内，你要求的基础鉴权；后续升级 HMAC token）
- 入库 JSON 契约（README 已定义的 14 个字段，含 error_reason 枚举）
- 标准指令：`上传错题`（批量入库）、`查错题`、`错题统计`、`出重做卷建议`
- 上传前先展示清单确认，防止误传

**鉴权方案（MVP）**：写接口用 `X-API-Key` 请求头；扫码提交接口暂保持免鉴权（阶段 2 加签名 token，已列入待办）。查询类接口对管理页走浏览器内 Key，对我走 API Key。

### 3. 错题查看前端（挂在 5173 下）
采用 Vue 3 + TS + Vite 现代前端工程 `mistake-book-view`（dist 产物部署）：
- nginx 增加一段 `location /cuoti/ { proxy_pass http://127.0.0.1:8090; }`（不剥离前缀，由 Go 托管）
- Go `main.go` 增加 `BASE_PATH=/cuoti` 路由组前缀（约 10 行）
- 三个页面的绝对路径（`/api/...`、`/static/app.js`、`/print`）改为前缀感知（约 10 行）
- 地址：`http://${SERVER_IP}:5173/cuoti/`，首次打开输一次 API Key 即可

### 4. AI 智能体内置生成错题网页
两种方式并存：
- **方式 A（默认）**：直接打开 `/cuoti/` 管理页（实时数据）
- **方式 B（对话内）**：你说"生成错题网页"，我调 API 取数 → 生成本地快照 HTML（按科目分组、含统计卡片）→ 弹出预览，可保存/分享。适合发给别人看或离线翻阅。

### 5. 薄弱板块分析
你问"我数学哪个板块薄弱"，我：
1. 调 `GET /api/v1/stats`（已有：知识点排行、科目分布、重做通过率）+ 必要时拉错题明细
2. 按科目 × 知识点 × 错误原因交叉分析：未掌握错题最多、重做通过率最低的知识点 = 薄弱板块
3. 给出结论 + 建议重做范围（可接"出重做卷"指令）

**数据质量前提**：我入库时知识点标签用统一词表（先内置初中各科核心知识清单，随使用沉淀），保证统计不碎片化。

## 三、部署步骤（确认后执行，约 20 分钟）

1. **改代码**（本地）：`BASE_PATH` 路由组 + 前端路径适配（3 个 html + main.go + handler 微调）
2. **编译**：`GOOS=linux GOARCH=amd64 go build`，连同 `web/` 打包 scp 到 `/opt/mistakebook/`
3. **建库**（需要你配合）：在服务器执行建库 SQL（或你给我 MySQL root 密码我来执行）：
   ```sql
   CREATE DATABASE mistakebook DEFAULT CHARSET utf8mb4;
   CREATE USER 'mistakebook'@'127.0.0.1' IDENTIFIED BY '<生成随机密码>';
   GRANT ALL ON mistakebook.* TO 'mistakebook'@'127.0.0.1';
   ```
4. **systemd 服务**：`mistakebook.service` 监听 `127.0.0.1:8090`，环境变量：`DB_DSN`、`API_KEY=<随机长串>`、`BASE_PATH=/cuoti`、`PUBLIC_BASE_URL=http://${SERVER_IP}:5173/cuoti`
5. **nginx**：在 5173 的 server 块追加 `/cuoti/` location，`nginx -t && reload`（不影响高架题库）
6. **验证**：healthz / 建一条测试错题 / 网页打开 / 手机扫码页打开
7. **写 skill**：创建 `~/.workbuddy/skills/mistakebook/`，写入地址 + Key + 契约 + 指令
8. **交付验证清单**给你逐项过
